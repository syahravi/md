Markdown editor

Write on the left and the preview updates on the right as you type. Math works with LaTeX syntax. Your text stays in this browser (localStorage); nothing is uploaded.

Shortcuts

Ctrl + DSwitch view: split, preview only, editor only
Ctrl + PPrint or save as PDF
Ctrl + SSave the source as a .md file
Ctrl + Shift + OOpen a .md file (or drop one on the page)
Ctrl + Shift + LLaTeX on or off
Ctrl + Shift + DDark mode on or off
Ctrl + Shift + RSerif (Computer Modern) or sans-serif preview
Ctrl + Shift + HShow this help
F11Full screen (in most browsers)

Markdown

# Title
## Subtitle
This is *italic* and this is **bold**.
This is a [link](http://www.example.com/) and this is an ![image](imagelink.jpg).
Write code with `...` or indent a paragraph by 4 spaces.
> This is a quote.

Editing shortcuts: Ctrl + B bold, I italic, Q quote, K code, G image, O numbered list, H heading, R rule, Z undo, Y redo.

LaTeX

This formula $x^2+1$ is shown inline.
This formula $$x^2+1$$ is shown in its own paragraph.

Page break

\pagebreak starts a new page when you print or export to PDF.
